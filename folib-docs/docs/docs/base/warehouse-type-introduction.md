## 本地仓库 (Local Repository)
本地仓库是制品库中最基础的存储类型，用于直接存储和管理开发团队发布的制品、构件或包。通常由自己管理，直接存储所有的构件信息，包括源码包、二进制文件、配置文件等。开发人员将自己的制品上传到本地仓库，并由其他团队成员或系统进行下载。

## 代理仓库 (Proxy Repository)
代理仓库是用来从远程仓库（例如Maven中央仓库、Docker Hub等）下载和缓存制品的。它充当本地仓库和远程仓库之间的中介，当本地仓库缺少某个制品时，代理仓库会将其从远程仓库下载并缓存起来，供后续使用。

## 组合仓库 (Virtual Repository)
组合仓库是将多个仓库（本地仓库、代理仓库等）组合在一起，通过一个统一的入口来访问这些仓库中的制品。允许在一个虚拟的仓库中同时访问多个本地仓库和代理仓库，从而简化了访问和管理。
