# 制品分析概述

Folib支持从组件、漏洞、许可证三个维度对制品进行扫描和分析。


| 名词   | 解释                                                                                                           |
|--------|--------------------------------------------------------------------------------------------------------------|
| **组件** | 软件制品中具有特定功能的独立单元，通常包含名称、版本号、组名称等信息，用于构建和运行软件系统。**制品扫描**板块中的组件是指制品中的所有类型的组件（包括开源组件和自研组件等等），**开源组件**板块中的组件仅指开源组件。 |
| **漏洞** | 软件制品中存在的安全缺陷或弱点，可能导致系统被攻击或数据泄露，按严重程度分为严重、高危、中危、低危。                                                           |
| **许可证** | 用于规定组件或制品的使用、分发和修改等法律条款的文件或标识，如开源许可证（MIT、Apache等）或商业许可证。                                                     |

## 界面说明

## 制品扫描

制品扫描板块主要分为**制品扫描数据列表**和**制品详情界面**两个界面。

**制品扫描数据列表**包含平台所有扫描成功的制品，点击目标制品的制品路径即可跳转至**制品详情界面**。

详情请见使用手册 [制品分析-制品扫描](../artifact-analysis/artifact-scanning.md)。

## 开源组件

开源组件板块主要分为**组件列表**和**组件详情界面**两个界面。

**组件列表**展示了平台中所有的开源组件，点击目标组件的组件名称即可跳转至**组件详情界面**。

详情请见使用手册 [制品分析-开源组件](../artifact-analysis/open-source-components.md)。

## 漏洞库

漏洞库板块主要分为**漏洞列表**和**漏洞详情界面**两个界面。

**漏洞列表**展示了平台中所有的漏洞，点击目标漏洞的漏洞编号即可跳转至**漏洞详情界面**。

详情请见使用手册 [制品分析-漏洞库](../artifact-analysis/vulnerability-library.md)。

## 证书库

证书库板块主要分为**证书列表**和**证书详情界面**两个界面。

**证书列表**展示了平台中所有的证书，点击目标证书的许可证编号即可跳转至**证书详情界面**。

详情请见使用手册 [制品分析-证书库](../artifact-analysis/certificate-library.md)。
