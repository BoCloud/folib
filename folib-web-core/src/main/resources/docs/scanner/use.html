# 全局漏洞扫描与安全

# 介绍

FOLIB基于全球开源安全开源漏洞库NVD以及国内安全漏洞库CNVD为公共数据基础。 实现通过平台枚举标识来实现每个依赖包的安全识别与CVE分析，并根据图数据库实时依赖关系处理、安全范围识别、跟踪与告警。为企业的云原生技术转型与快速迭代提供有利支撑。

# 名词解释

  • 扫描包总数： 表示当前平台所有已经开启安全扫描，并且经过安全扫描的总包数量

  • 漏洞包数量： 表示当前平台所有已经开启安全扫描，并且经过安全扫描发现的所有具有安全漏洞问题的包总和(包含所有高中低级别)

  • 扫描依赖数量： 表示当前平台所有经过扫描之后，发现的所有依赖以及底层依赖数量，通常情况下依赖总数大于包总数。

  • 漏洞总数： 表示当前平台所有已经开启安全扫描，并且经过安全扫描的发现的漏洞总数量，

    注意

    这里的漏洞总数可能会重复存在原因是，同一个漏洞可能存在多个包或者仓库中，这里该指标是一个求和统计。

# 漏洞扫描使用

  • 安全扫描开启

    安全扫描开启功能需要【管理员角色】在仓库详情页进行开启。如下图：

  • 仓库维度查看漏洞情况

    当仓库被开启安全扫描时，平台会自动将该仓库下的所有制品进行安全扫描，并出具所有制品的安全报告。可以通过【安全扫描】菜单进入，选择对应的仓库，进入仓库的安全页面，可以查看每一个软件包的安全报告。

    注意

    这里的漏洞建议修复版本是来自于NVD或CNVD

  • 仓库软件包维度查看有问题的包提示

    在制品仓库维度，如果发现该制品存在漏洞，则会在【制品包详情页面】进行展示，并且可以点击查看漏洞详情。如下图搜索示例：

# 漏洞图谱与黑白名单

平台中一个CVE漏洞往往会涉及到多个不同的存储空间和制品仓库。该功能主要给【平台管理员】进行识别，一个漏洞会影响到哪些仓库，分别在哪些制品包中存储。并且通过黑白名单进行阻止用户下载
