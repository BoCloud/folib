# 查询制品

GET /api/fql

# 请求参数

名称 位置 类型 必选 中文
artifactName query string 否 制品名称
beginDate query string 否 开始时间
endDate query string 否 结束时间
limit query integer 否 查询条数
metadataSearch query string 否 元数据
openRepository query string 否 是否开启仓库查询
page query integer 否 当前页数
regex query string 否 正则表达式
repositoryId query string 否 仓库id
repositoryIds query array[string] 否 仓库id集合
safeLevel query string 否 排序等级
sortField query string 否 排序字段
sortOrder query string 否 排序比重
storageId query string 否 存储id
