# 存储空间管理

制品库存储空间管理主要使用的对象是制品仓库的管理【admin角色】。

  • 存储空间名词解释

    存储空间表示一个独立的隔离环境，该空间下可以创建您想要使用的仓库，您只需选择新建即可。不过，目前还不支持设定存储空间大小，未来将会支持。

  • 存储空间创建

    登录管理员账号，点击左侧菜单【制品仓库】选择【存储列表】的“＋”号，添加存储空间。输入存储空间名称，并分配相应的成员。如图所示：

  • 成员分配修改与删除

    选择您要修改的存储空间，点击右侧的“修改”设置图标。如果您需要将该成员加入或移除时可以使用该功能。*注意：不要随意强制删除存储空间。

# 制品仓库创建

制品库管理主要包含：创建制品仓库，删除制品仓库，以及各个不同仓库。

  • 策略

    【本地】：用来存储二方包，自主研发上传的包库。

    【远程】：选择远程后，需要配置下一步第三方代理的，该功能是用来做仓库远程代理使用，例如代理aliyun maven等

    【组合】：该仓库类型是一个虚拟仓库，是将多个同类型的仓库进行自由组合，形成一个下载入库给到用户使用。

  • 版本策略

    版本策略是用来做制品包版本限制使用的，一般在本地仓库中进行使用，如果是release库则只能存储release而不能存储snapshot；

    注意事项

    如果是代理库，组合库，通常选择mixed混合模式。在没有版本管理的情况下，本地库也可以采用mixed，如果细分严格化管理可设定snapshot和release

  • 制品大小限制

    制品大小限制，默认是100M，可以按照需求调整，该功能是为了限制单个制品包大小使用的，防止会不规范的用户将超大文件上传等。

    注意

    一般情况下，只有raw仓库(成品库)需要设置的更大一些，可能一些安装包比较大。

  • 其他说明

    【回收站开启】：开启回收站在制品包删除后可以通过后台api进行从回收站回收。

    【删除允许】：有的仓库可以设置不允许删除，则用户在使用过程中无法删除。

    【上传部署允许】：在本地类型仓库中，可以开启允许上传，则可以通过命令行工具，或者依赖工具进行上传制品安装包到仓库中。

    【上传覆盖允许】：开启该功能，则同版本好的制品安装包将会被直接覆盖，旧版本的则不保留，如果不开启，则默认通过小版本号（时间戳）进行，时间最新的则优先下载。

    【浏览允许】：该功能是html Bower模式，可以通过浏览器进行浏览与下载该仓库的目录的文件。主要用来对外界开放使用。

    注意

    如果发生一些无法上传，访问401，404等情况时请优先考虑以上设置是否正确

# 远程代理库设置

远程代理库设置，只能在创建时选择【远程】策略，点击【下一步】进入远程配置画面，如下图所示：

  • 代理设置 代理设置主要在当前制品库无法访问代理地址的情况下（例如内网环境），通过开启代理经过一个proxy来访问代理地址而使用的，如果proxy设有用户名密码，则在代理配置中选择通讯协议【TCP/HTTP】，输入用户名密码。
  • 用户名密码 代理库用户名密码是用来，当目标代理仓库需要用户名密码才能访问时，需要输入用户名密码以确保能够下载索引。

    使用场景

    例如要代理jfrog或者nexus现有的仓库，则需要输入用户名密码。
