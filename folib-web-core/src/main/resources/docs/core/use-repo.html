# 全局配置

全局配置主要用来给平台管理员【admin角色】进行配置本平台基本的全局性设置而使用的。

  • 基础信息配置

    可以对本平台的应用名称、基础url、端口号进行设置。

    使用场景

    一般情况下，我们通过内网部署后，通过代理的公网进行访问，那么可以将公网ip做基础url和端口进行设置

  • 网络代理配置

    网络代理为平台基本的全局网络代理（proxy）。

    使用场景

    一般情况下，您部署的机器无法连接外网时，可以通过该配置来实现代理能力

# 安全配置

用来配置全局性的安全策略，例如：安全扫描定时时间，全局白名单，以及红线阀值等设置

注意

该功能将会在1.0.2版本中发布。
