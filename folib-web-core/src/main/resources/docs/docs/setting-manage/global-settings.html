# 全局设置

在全局设置中，可以设置 全局配置 、 安全策略 、 LDAP配置 、 SSO配置 、 元数据配置 、 节点分发配置 、 联邦晋级策略 、 自定义布局 、 webhook 、 审计配置 以及 定时策略 等。

# 全局配置

全局配置主要用来给平台管理员 【admin角色】 进行配置本平台基本的全局性设置而使用的。

  1. 基础信息配置: 可以对本平台的应用名称、基础url、端口号进行设置。

TIP

💡 一般情况下，我们通过内网部署后，通过代理的公网进行访问，那么可以将公网ip做基础url和端口进行设置.应用名称修改会自动修改到配置文件。

baseurl: 如果你使用了反向代理公网等情况下可以使用它。

folib-Server: 服务的后端通信端口。

  1. SMTP配置: 用来设置系统邮箱，可以对本平台用户名、密码、HOST、端口、协议类型进行设置。

TIP

💡 程序中某些事件会对相关用户进行邮件通知。

  1. 网络代理设置: 网络代理为平台基本的全局网络代理（proxy），通过以下参数配置来实现代理服务器的连接和通信：
  • 代理用户名：用于代理服务器的身份认证，需要提供有效的用户名以获得访问权限。
  • 代理密码：配合用户名使用的认证凭据，用于验证用户身份的安全信息。
  • 代理地址：代理服务器的IP地址或域名，指定代理服务器在网络中的具体位置。
  • 端口号：代理服务器使用的网络端口，用于区分同一服务器上的不同服务（如8080）。
  • 代理类型：支持以下几种代理协议：
    • HTTP代理：专门用于HTTP协议的代理服务。
    • SOCKS代理：支持多种协议的通用代理（SOCKS4/SOCKS5）。
    • 透明代理：对客户端不可见的代理服务。
    • 匿名代理：提供IP地址隐藏功能的代理服务。

TIP

这些参数通常在客户端的网络设置中配置，或者在使用命令行工具时作为参数提供。正确配置这些参数对于确保网络代理正常工作至关重要。

💡 使用场景:

一般情况下，您部署的机器无法连接外网时，可以通过该配置来实现代理能力

例如需要配置代理后可以访问公网

可以通过代理获取公网仓库的依赖

  1. CORS配置

跨域问题产生的根本原因在于浏览器的同源策略。同源策略限制了从一个源加载的文档或脚本与另一个源的资源进行交互的能力。这种策略是为了防止恶意文档窃取数据 。在输入框中设置平台跨域的地址，或者点击选择开启下【开启】按钮，该平台所有请求将不再有跨域限制，不同源之间的资源可以安全地共享。

# 安全策略

点击左侧导航栏 【设置管理】-【全局设置】-【安全策略】 ，安全策略提供了全局性的安全管理机制，包括以下四种核心功能：

  1. 白名单: 白名单机制允许管理员将特定的漏洞标记为可信任状态：
    • 通过输入漏洞编号、License将其加入白名单，同时设置有效期
    • 在有效期内，白名单中的漏洞、License将被系统忽略，不再触发风险提示
    • 适用于已确认无风险或风险可控的漏洞

TIP

💡 提供 漏洞 、 License 的白名单

  1. 黑名单: 黑名单用于严格控制高风险漏洞
    • 将高危漏洞编号、License、包添加至黑名单，同时设置有效期
    • 在有效期内，黑名单中的漏洞、License、包将被禁止下载和使用
    • 可防止用户和其他工具访问存在高危漏洞的组件

TIP

💡 提供 漏洞 、 License 、 包 的黑名单

🤖 对于包的黑名单，可以限制版本，如 <= 2.1.10 版本的包被添加如黑名单， 2.1.10 版本后的版本正常使用。

  1. 通知设置

配置系统的安全通知机制：

  • 设置风险等级通知阈值
  • 配置通知接收对象范围
  • 自定义通知触发条件

  1. 阻断策略

配置系统的自动阻断规则：

  • 仓库阻断：针对仓库的阻断策略
  • 漏洞黑白名单阻断：自动阻断黑名单中的漏洞组件
  • 包名阻断：基于包名的精确阻断控制
  • License黑白名单阻断：自动阻断License黑名单中的制品

# LDAP配置

在统一用户要单点登录方面，您可以通过【LDAP配置】输入基本配置，点击【下一步】进入用户角色映射来完成LDAP配置。

# 节点许可配置

证书配置需要您申请获取到证书后，填入右边的文本框并点击激活即可。

TIP

💡 正式激活需要联网，试用激活只有1个月时间，无需联网，正式环境如果无法联网，请通过上方全局代理一个可以访问外网的机器进行代理激活。

# SSO配置

可通过新增客户端信息进行本产品的登陆信息转跳。

参数说明：

  • clientId：客户端唯一标识，客户端id。
  • 客户端名称：客户端名称。
  • 登陆地址：单点登录页面所对应的url地址,由第三方登录系统提供。
  • 退出登陆地址：单点登录页面退出登录所独调用的url地址,由第三方登录系统提供.用于清除服务端的会话。
  • 退出重定向url：退出登录后重定向地址。
  • 登陆重定向地址：登陆重定向地址。
  • 获取token接口地址：获取accessToken的接口地址。
  • 配置说明：该配置的描述信息。

# Webhook

添加Webhook配置url，访问令牌 Header X-Token和触发事件场景的选择。

触发事件：

  • 制品上传：上传制品时触发 URL
  • 制品更新：再次上传同一制品时触发 URL
  • 制品下载：下载制品时触发 URL
  • 制品删除：删除制品时触发 URL
  • 目录删除：删除制品目录时触发 URL
  • 安全阻断：下载被安全策略阻断时触发 URL
