# 介绍

# 产品背景

随着国产化软件进程的发展，在制品库该核心技术领域，国内极少存在自主可控的商业级制品仓库来支撑国内企业IT的安全发展，随着devops的不断兴起，客户对商业版制品库的认知越来越高，需求也越来越多。经过调研，我们认为：国内市场需要一款能够与jfrog进行竞争的商业级国产制品库。
